# ✨ My Links

A pretty, popl-style link-in-bio page — fully editable right in the browser.

## Features
- Change your profile photo, banner, name, and bio
- Add your own links for any project (Payhip, Etsy, X, …)
- **Automatic icons**: every link gets a cute, on-brand icon designed for it automatically — works for any site you add
- Card-style or round icon-style links, reorder them however you like
- 5 feminine color themes (Blush, Sage, Lavender, Honey, Sky)
- Edits save automatically in your browser

## Use
Open `index.html`, tap **✏️ Edit page**, make it yours. That's it.

Live: https://misoprettystacks.github.io/links/
